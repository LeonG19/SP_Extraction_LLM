HOW IT WORKS NOW:
─────────────────
For each attack method (fuzz, re, leakagent, pleak):

1. Load good_prompts.csv (training file with reward scores)
2. Select top 5 by reward: prompts.nlargest(5, "reward")
3. These same 5 prompts test against ALL 4 models:
   - llama3.1-8b
   - llama3.1-70b
   - mistral-7b
   - qwen3.5-27b
4. For each (system_prompt, attack_prompt) pair:
   - Query model 10 times
   - Calculate ROUGE-L, WES, LCS
   - Report highest similarity


EVALUATION COUNTS:
──────────────────
16 evaluations per phase:
  - 4 attack methods × 4 models × 1 mode
  - Example: Fuzz vs llama3.1-8b, Fuzz vs llama3.1-70b, etc.

250 samples per evaluation:
  - 50 system prompts × 5 attack prompts
  
2,500 queries per evaluation:
  - 250 samples × 10 queries per sample

  - 72 total evaluations × 2,500 queries = 180,000 queries
