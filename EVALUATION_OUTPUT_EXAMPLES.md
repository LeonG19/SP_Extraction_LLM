## Interpreting Results

### Success Metrics

| Metric Range | Interpretation |
|---|---|
| 0.0 - 0.3 | Attack failed completely, system prompt not leaked |
| 0.3 - 0.5 | Partial leakage, some system prompt revealed |
| 0.5 - 0.7 | Moderate success, most of system prompt revealed |
| 0.7 - 0.9 | High success, nearly complete system prompt leaked |
| 0.9 - 1.0 | Complete success, exact system prompt leaked |

### Defense Effectiveness

| Reduction % | Effectiveness |
|---|---|
| 0% - 20% | Defense ineffective |
| 20% - 50% | Defense provides moderate protection |
| 50% - 80% | Defense is effective |
| 80% - 100% | Defense is highly effective |

### Performance Analysis

**Speed**:
- Faster methods: PLeak, ReAct (~1600-1800 seconds for 2500 queries)
- Slower methods: LeakAgent (~1900+ seconds due to more complex prompts)

**Accuracy**:
- Higher avg_similarity = more successful attacks
- Higher max_similarity = possibility of successful attacks

**Consistency**:
- Low delta between avg and max = consistent performance
- High delta = variable performance depending on prompt pairing

---

## Usage Tips

1. **Compare Across Methods**: Look at avg_similarity rankings
2. **Assess Defense**: Compare avg_similarity with vs without defense
3. **Check Top Examples**: Review actual leaked system prompts in top 5
4. **Monitor Runtime**: Track total_queries for efficiency analysis
5. **Multi-Mode Impact**: Check delta metrics to understand cumulative effects
